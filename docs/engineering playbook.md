# Engineering Playbook — MVP Bares de Sevilla

## Propósito

Este documento define cómo se desarrolla, organiza y evoluciona el proyecto MVP Bares de Sevilla.

Su objetivo es mantener una metodología de trabajo ordenada y profesional durante todo el ciclo de desarrollo.


---

# 1. Visión del proyecto

## Problema

Encontrar bares interesantes de Sevilla es complicado debido a que la información está dispersa entre diferentes plataformas.


## Solución

Crear una aplicación web que centralice bares de Sevilla organizados por:

- zonas;
- categorías;
- características;
- información práctica.


## Objetivo inicial

Crear un MVP funcional que permita validar la idea antes de desarrollar funcionalidades avanzadas.


---

# 2. Alcance del MVP

El MVP incluye:

- listado de bares;
- categorías;
- zonas;
- fichas individuales;
- información básica;
- filtros.


Fuera del MVP:

- IA avanzada;
- chatbot;
- usuarios;
- favoritos;
- recomendaciones inteligentes;
- aplicación móvil.
